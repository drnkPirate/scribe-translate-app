# Bundle-size optimization

- `functional`: the packaged sidecar starts and processes the fixed WAV fixture.
- `output_identity`: Dutch and French text exactly match the baseline.
- `installer_bytes`: Windows NSIS installer size; the optimization target.
- `bundle_bytes`: unpacked sidecar payload size; a fast local diagnostic.

The model IDs, revisions, hashes, inference settings and model downloads are off-limits.
